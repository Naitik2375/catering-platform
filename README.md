# Catering Search Platform

## Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: Node.js, Express

## Features
- View all caterers
- Search by name
- Filter by price
- Add new caterer (API)

## Setup Instructions

### Backend
cd backend  
npm install  
npm start  

### Frontend
cd frontend  
npm install  
npm run dev  

## API Endpoints
- GET /api/caterers
- GET /api/caterers/:id
- POST /api/caterers
